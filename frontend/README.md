# Arbitr AI Frontend — веб-кабинет финансового управляющего

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

## Сборка

```bash
npm run build    # → dist/
```

## Структура

```
src/
├── components/    # UI-компоненты
├── pages/         # страницы: дашборд, дела, запросы
├── services/      # API-клиенты (axios)
├── hooks/         # React-хуки
└── types/         # типы данных
```
