# lab — лаборатория арбитражного анализа

Субагенты Claude Code для анализа арбитражных дел. Правила и порядок работы — в [CLAUDE.md](CLAUDE.md), схема ролей — в проектном документе «Лаборатория арбитражного анализа: состав агентов».

| Агент | Роль |
| --- | --- |
| (основная сессия) | оркестратор: ведёт дело по шагам, собирает итог для юриста |
| intake | принимает файлы, извлекает текст, составляет опись |
| case-mapper | карта дела и хронология со ссылками |
| fact-checker | сверка карты с первичными документами |
| norms-researcher | нормы и их редакции через коннектор законодательства |
| case-law-researcher | судебная практика только из проверяемых источников |
| finance-analyst | анализ БФО и признаков неплатёжеспособности |
| procedure-expert | сроки, подсудность, процессуальные действия по АПК РФ |
| bankruptcy-expert | банкротство, оспаривание сделок, субсидиарная ответственность |
| contracts-expert | договорные споры: поставка, подряд, услуги и др. |
| corporate-expert | корпоративные споры |
| drafter | черновик документа |
| critic-council | три голоса против позиции: оппонент, судья, адвокат дьявола |
| checker | проверка каждой ссылки и чек-лист юрдокумента |

Первое дело — отзыв по субсидиарной ответственности (Вернер А.В.); содержание дела ведётся в отдельном треде проекта.

Запуск: `cd lab && claude`, затем, например: «новое дело cases/verner: подготовь проверенный черновик отзыва».
