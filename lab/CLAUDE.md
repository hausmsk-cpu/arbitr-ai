# Лаборатория арбитражного анализа

Набор субагентов Claude Code для подготовки черновиков правовой позиции и процессуальных документов по делам в арбитражных судах РФ: банкротство и субсидиарная ответственность, договорные споры (поставка, подряд и др.), корпоративные споры.

Запуск: `cd lab && claude`. Агенты лежат в `lab/.claude/agents/`.

## Обязательные правила для всех агентов

1. **Никаких выдуманных норм, дел, цитат и цифр.** Номер статьи, реквизиты акта, номер дела, дата или сумма приводятся только если они найдены в источнике в этой сессии. Иначе — пометка `[НЕ ПРОВЕРЕНО]`.
2. **Каждое утверждение со ссылкой.** Норма: акт, статья, часть/пункт, редакция на дату. Факт: файл дела и страница/абзац.
3. **Неуверенность видна.** Писать «не уверен», «требует проверки», а не догадку в утвердительной форме.
4. **Судебная практика — только из источника.** Подключённой базы практики нет. Агент цитирует только акты, загруженные юристом в папку дела, или найденные на kad.arbitr.ru в этой сессии (с номером дела и датой акта). Цитировать дела по памяти запрещено.
5. **Редакция нормы на дату правоотношения.** Проверять действующую редакцию на дату спорных событий, а не только текущую.
6. **Пишет один, проверяет другой.** Черновик не отдаётся юристу без прохода `critic-council` и `checker`.
7. **Итог — черновик для юриста.** Агенты ничего не подают и не отправляют за пределы папки дела.

## Источники

- **Коннектор законодательства РФ** (MCP, инструменты вида `search_legislation`, `get_provision`, `check_currency`, `validate_citation`, `format_citation`). Ограничения на 10.10.2026: федеральные акты с pravo.gov.ru, последняя загрузка 25.02.2026; нет судебной практики, региональных актов, мало исторических редакций; не официальная публикация. Всё, что позже 25.02.2026, проверять отдельно.
- **kad.arbitr.ru** — карточки дел и судебные акты. Автоматический доступ не настроен и не проверен; пока только ручная загрузка актов юристом.
- **Файлы дела** в `cases/<дело>/`.

## Папка дела

```
cases/<краткое-имя>/
  input/        исходные файлы от юриста (не меняются)
  text/         извлечённый текст
  case-map.md   карта дела (стороны, даты, требования, суммы, доказательства)
  discrepancies.md
  research/     norms.md, case-law.md, finance.md, procedure.md, expert-*.md
  drafts/       черновики документа (v1, v2, ...)
  review/       critic-council.md, checker.md
  log.md        журнал: кто что сделал и когда
```

Содержимое `cases/` не коммитится (персональные данные клиентов), кроме `cases/README.md`.

## Порядок работы (основная сессия = оркестратор)

Субагенты не запускают других субагентов, поэтому дело ведёт основная сессия Claude Code в папке `lab/`. Задача: довести запрос юриста до проверенного черновика, не делая работу экспертов за них.

1. Уточни у юриста, если не ясно: папка дела, какой документ нужен (отзыв, иск, жалоба, позиция), чья сторона, срок.
2. Создай структуру папки дела (см. выше), если её нет.
3. Запускай субагентов по порядку: `intake` → `case-mapper` → `fact-checker` → `norms-researcher`, `case-law-researcher`, `finance-analyst` (если есть финансовые данные) → `procedure-expert` + профильный эксперт → `drafter` → `critic-council` → `checker`.
4. Профильного эксперта выбирай по предмету спора: банкротство/субсидиарка → `bankruptcy-expert`; договор → `contracts-expert`; корпоративный спор → `corporate-expert`. Можно нескольких.
5. Если `fact-checker` нашёл существенные расхождения — верни `case-mapper` и/или спроси юриста до исследования.
6. Если `checker` вернул замечания — отправь `drafter` на доработку, затем снова `checker`. Не больше трёх кругов; потом отдай юристу с открытыми замечаниями.
7. Каждый шаг записывай в `log.md`: дата, агент, что сделано, какие файлы созданы.

Итог юристу: путь к черновику, список непроверенного (`[НЕ ПРОВЕРЕНО]`), открытые вопросы, решения, которые принимает только юрист.
