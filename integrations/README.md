# Справочник по интеграциям Arbitr AI

В данной директории — каркасы интеграций с государственными органами и сервисами
для автоматизации рутинных операций финансового управляющего.

## Интеграции

| Директория | Орган/сервис | Способ |
|------------|--------------|--------|
| `fns/` | ФНС России | REST API (api-fns.ru), СМЭВ |
| `rosreestr/` | Росреестр | СМЭВ, платные API (выписки ЕГРН) |
| `fssp/` | ФССП | Открытый API банка данных (api-ip.fssp.gov.ru) |
| `post/` | Почта России | API заказных писем (api.pochta.ru) |

## Способы отправки

1. **Прямое API** — для органов с открытыми API (ФНС, ФССП)
2. **Электронные заказные письма** — через API Почты России (юридически значимо)
3. **RPA (Playwright)** — для порталов без API (ГИБДД, ГИМС, Гостехнадзор)
4. **Ручная отправка** — с фиксацией ШПИ в системе

## Требования к адаптерам

- Каждый адаптер реализует интерфейс `IntegrationClient` (`send_request`)
- Единый формат ответа `IntegrationResponse` (ok, data, error)
- Логирование через structlog
- Секреты — только из Harness Secrets (переменные окружения)
- Feature Flags — управление включением (например `enable_rosreestr_api`)
